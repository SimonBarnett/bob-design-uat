# Graphics UAT

Parent skill: `design-uat`. Same G1/G2/G3. Do not add a G4.
Do not rewrite artwork.

## When

The brief names **SVG**, icons, logos, or other still graphics (not a full product screenshot and not a raw `.ai` — that is `illustrator-uat`).

## Procedure

1. Inventory each file the brief names (name, size, artboard). Missing required size/export is G2 / `brief`.
2. **G1:** readable text in SVG (`<text>`) or on the raster. If text was converted to outlines, say so — do not invent the string from the path.
3. **G2:** alignment, viewBox, overflow, contrast vs brief tokens.
4. **G3:** marks, words, or icons the brief did not authorize.
5. Same report template and worker verdicts as `design-uat`.

## Do not

- Invent missing SVG variants.
- Stamp ready for human UAT.
- Commit secrets.
